蓝色大肥鱼桌宠 · 使用说明

1. 双击「蓝色大肥鱼.exe」启动，不需要安装。
2. 如果 Windows 提示“已保护你的电脑”，点“更多信息 → 仍要运行”。
   这个程序是本地编译的，没有购买数字签名。
3. 点鱼鱼打开聊天窗，点上方的“设置”，填入你自己的 DeepSeek API Key，保存并测试连接。
4. 没有 Key 也能先玩：她会进入离线试用模式。
5. 右下角「喂白饭」可以看她吃白饭；拖动她会变成害羞表情；右键还有散步、摸头、睡觉等菜单。
6. 不想让她自己乱走，可以在设置里关闭“允许自由散步”。

系统要求：
- Windows 10 / 11（推荐）
- .NET Framework 4.8（现代 Windows 一般已自带；如果启动提示缺少，请到微软官网安装）

数据位置：
- 设置和聊天记录保存在：%APPDATA%\BlueFishPet\
- 如果该目录不可写，会保存在程序旁边的 data\ 文件夹。
- 分享程序时不需要分享这个数据目录；也不要把自己的 API Key 发给别人。

这个程序是个人同人桌宠，不是 DeepSeek 官方产品。
